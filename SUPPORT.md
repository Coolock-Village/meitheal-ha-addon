# Meitheal support

## A download fails

Open the Supervisor log and look for the first error for Meitheal. If it shows `401` for the image download, follow [the install issue](https://github.com/Coolock-Village/meitheal-ha-addon/issues/1).

For a different error, include the add-on name, version, Home Assistant OS version, and device architecture in your report.

## A task or routine does not work

Describe the last time it happened. Include the steps you took, what you expected, what happened, and how you finished the work.

## A guide is hard to follow

Link to the guide and name the first step you could not finish. Include the label or error that you saw.

[Search issues or open a report](https://github.com/Coolock-Village/meitheal-ha-addon/issues). Remove tokens, private addresses, and household details. For a suspected vulnerability, use the [private reporting route](SECURITY.md).
