# Create your first task

Use a job you already need to do, such as **Replace the kitchen filter**.

1. Open **Today** in Meitheal.
2. Find **Add a task** in **Overview**.
3. Enter **Replace the kitchen filter**.
4. Select **Add**.
5. Open **Work**.
6. Find the task under **Due Today**.

When you finish the job, use the checkbox next to the task. Meitheal records it as complete.

If you cannot find the task in **Today**, search for its title. Check the due date in the task details.
