# Contributing to Meitheal

You can help improve setup steps, correct a guide, or report a problem you can reproduce. Follow the [code of conduct](CODE_OF_CONDUCT.md).

## Report what happened

Search the [issues](https://github.com/Coolock-Village/meitheal-ha-addon/issues) for the problem. If you find a match, add any new steps or results.

For an improvement, describe the last time you did the task. Explain where you got stuck and what you did next.

For a suspected vulnerability, use the [private reporting route](SECURITY.md).

## Improve a guide

1. Open the guide you want to change.
2. Use the button to edit the file.
3. Check the instructions against the app or store.
4. Open a pull request.
5. List the version you used and the steps you checked.

The add-on setup guides sync from the private source repository. The maintainer will apply fixes there so they stay in both places.

Use sample tasks in screenshots. Remove access tokens, addresses, and household details from logs and images.
